# v1.11 — 움직이는 세카이·캐릭터·적 그래픽 (개발 중)

- 7개 세카이 환경에 각기 다른 절제된 움직임 추가: 교실 창가 먼지와 시계, 스테이지 조명과 관객 응원봉, 스트리트 포스터, 원더랜드 회전목마와 풍선, 아무도 없는 세카이의 부유 조각, 닫힌 창의 미세한 흔들림, 열린 창의 꽃잎
- **모바일 성능:** 고정 타일·배경·랜드마크는 오프스크린 캔버스에 한 번만 그리고, 움직이는 환경 요소만 매 프레임 처리
- 26명 기존 4방향 캐릭터 PNG를 그대로 사용하면서 대기 호흡, 공격 돌진·반동, 소환 착지, 합성 승급 점프 적용
- **적 7종 완전 신규 코드 그래픽:** 뒤틀린 박자(일반), 화살형 돌진체(빠름), 스피커형 장갑체(느림·높은 HP), 반으로 갈라지는 악보(분열), 팔각형 차단 화음(둔화 면역), 소형 파편, 지휘봉·마스크 실루엣의 보스
- 적마다 서로 다른 움직임 주기. 보스는 일정 간격으로 주변 적을 1.35초간 가속하는 지휘 박자 효과
- 피격 상태·둔화 상태·보스의 박자 가속 상태를 원래 캐릭터와 구분해서 표시
- 기존 공격 26종 특수타, 1~4성 외형, 세카이별 소환 우선 추첨, 세카이의 마음 대사 컷인 유지
- 화면 흔들림·환경 움직임은 간소화 연출 또는 기기 모션 감소 설정에서 줄이도록 반영

**주의:** 원작 캐릭터 PNG를 재가공하거나 새 공식 적 이미지를 가져오지 않았습니다. 적은 새로 설계한 캔버스 그래픽입니다. 실제 모바일 기기에서의 성능·미술 완성도 최종 검수는 아직 필요합니다.

# 전투 완성도 개선 · 전투/소환/맵 패스 (v1.10, 프로토타입)

- **공격 차별화:** 기본 공격 유형 7종(관통, 폭발, 범위, 연타, 연쇄, 튕김, 둔화), 캐릭터 26명 각각의 특수 공격 모티프/주기/위력/효과
- **타격감:** 날아가는 투사체, 도착 후 피해 적용, 적 반동, 짧은 타격 효과음, 강타·피해 숫자·절제된 화면 진동
- **성급 1~4:** 스프라이트 원본 변형 없이 발밑 표식, 성급 배지, 고성급 장식과 합성 승급 연출 강화
- **세카이 보정 소환:** 선택한 맵의 유닛에 55% 우선 추첨. 기존 보유 유닛에 25% 재추첨(보유가 있을 때), 기타 전체 유닛에서 20%; 보유가 없으면 45% 전체 추첨. 우선 추첨 외 경로로도 해당 세카이 유닛이 나올 수 있으므로 최종 소속 확률은 55%보다 큽니다
- **맵 소속:** 교실=Leo/need, 스테이지=MORE MORE JUMP!, 스트리트=Vivid BAD SQUAD, 원더랜드=Wonderlands×Showtime, 아무도 없는=25시, 나이트코드에서., 극장판 창 맵 2종=버추얼 싱어(팬게임 전용 규칙; 원작 공식 소속이 아닙니다)
- **7개 맵:** 같은 11×12 정사각 타일 격자에서 세카이별 배경 오브젝트·출현 문양·분위기 추가. 맵 외형이나 타일 구조를 아이소메트릭으로 바꾸지 않음
- **세카이의 마음:** 1.62초 대사 컷인(약 0.62초 뒤 공격 적용), 여러 동시 발동은 순차 표시. 버추얼 싱어 그룹 스킬에는 여섯 명 전원 필요
- **접근성:** 모션 줄이기 설정 또는 기기 모션 감소 환경에서는 화면 흔들림 없음

**제한:** 여전히 개발 중 프로토타입이며, 모바일 실기기 검수·장시간 밸런스·UI 미술 완성도 검수는 별도로 필요합니다. 모든 대사는 이 게임용으로 새로 쓴 것이며 공식 대사나 음성 파일이 아닙니다.

# 전투 UI · 세카이의 마음 컷인 개선 (v1.9)

- 각 세카이의 마음 발동 시 캐릭터 정면 스프라이트, 캐릭터 이름, 직접 작성한 대사, 스킬명을 보여 주는 전투 컷인 추가
- 대사가 나온 뒤 약 0.62초에 실제 범위 공격을 발동. 다수 조합 발동 시 화면 연출을 순차 처리
- 한국어/일본어/영어 대사 지원, 간소화 연출 옵션 및 모션 감소 환경 대응
- 세로/가로 전투 조작 버튼을 짧고 터치하기 쉽게 재배치. 적 위험도 및 보스 웨이브 표시 개선
- 이미지 폴더는 원격 저장소의 대소문자 `Assets/`를 그대로 사용
- 별도의 성우 음성이나 원작 스킬 UI 이미지를 복제하지 않음. 26명 캐릭터 PNG는 사용자 제공 이미지를 사용

**상태:** 개발 중 프로토타입. 실제 스마트폰 기종별 시각 검증 및 게임 밸런스 개선은 계속 필요합니다.

# 프로젝트 세카이 랜덤 디펜스 — v1.2 (5개 세카이 맵 개편)

HTML5/CSS/JavaScript 기반 비공식·비영리 팬게임 프로토타입.

## GitHub Pages에 업데이트
1. ZIP을 풀어 `index.html`, `src/`, `styles/`, `assets/`, `.nojekyll`을 저장소 최상단에 업로드합니다.
2. 같은 이름의 기존 파일은 덮어씁니다. `styles/arcade.css`, `src/data/maps.js`, `src/core/SekaiMapArt.js`가 중요합니다.
3. GitHub Pages의 `main / (root)` 배포를 사용합니다. 배포 후 브라우저에서 강력 새로고침을 하면 최신 파일이 표시됩니다.

## 변경 내용
- 맵을 기존 13~14×19타일에서 **11×12타일**로 축소. 정사각형 타일은 그대로 유지.
- 맵을 3개에서 **5개**로 확대: 교실의 세카이(Leo/need), 스테이지의 세카이(MORE MORE JUMP!), 스트리트의 세카이(Vivid BAD SQUAD), 원더랜드의 세카이(원더랜즈×쇼타임), 아무도 없는 세카이(25시, 나이트코드에서.).
- 교실: 석양 창문·칠판·책상·피아노. 스테이지: 라이브 무대·조명·응원봉. 스트리트: 벽돌·포스터·카페. 원더랜드: 회전목마·색색의 어닝. 아무도 없는 세카이: 회색 구조물·트러스·삼각 기둥.
- 모든 맵은 서로 다른 형태의 **단일 폐회로**, 고유의 적 생성 타일, 겹치지 않는 가구/배치칸을 가짐.
- 배경·길·장식·타일은 외부 이미지 없이 Canvas로 그립니다. 캐릭터와 기존 UI 및 언어별 로고는 이전 버전 그대로 유지했습니다.
- 맵 선택 화면을 5개 선택지로 구성하며 작은 가로 화면에서는 한 줄 5개로 배치.

## 검증
- `npm test`: 26 캐릭터, 맵 5개, 경로 닫힘 및 중복 없음, 충분한 배치칸, 전투·합성·재화 로직, 로고 파일.
- Chromium 시뮬레이션: 390×844, 844×390, 320×568에서 맵 5종을 각각 선택 → 전투 시작 → 소환 → 로비 복귀, 브라우저 오류 없음.
- 모바일 세로/가로/태블릿 시뮬레이션 화면 렌더링 확인. 실제 휴대전화에서의 추가 점검은 별도 필요.

## 참고
원작 화면 이미지를 복사하지 않고, 공식 세카이 장소의 특징을 **독자적인 완전 탑뷰 도트 타일맵**으로 옮긴 버전입니다. 원작의 원근감 있는 배경을 그대로 복제한 것은 아닙니다. 팬게임의 배포 조건은 권리자 가이드라인을 따로 확인해 주세요.
