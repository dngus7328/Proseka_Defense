# 세카이 랜덤 디펜스 — HTML5 v0.4

이미지 없이 실행되는 비공식·비영리 팬게임 프로토타입.

## 실행·배포

1. ZIP 파일을 **압축 해제**합니다.
2. 압축 해제한 폴더 안의 `index.html`, `styles/`, `src/`, `.nojekyll` 등의 파일을 GitHub 저장소의 **최상위 경로**에 올립니다. 폴더를 한 단계 더 감싸서 올리지 않습니다.
3. GitHub 저장소 **Settings → Pages → Deploy from a branch → main / (root)** 로 설정합니다.
4. 배포되면 `https://사용자이름.github.io/저장소이름/` 으로 접속합니다.

기존 저장소에 올리는 경우에는 같은 경로의 기존 파일을 **전부 덮어써야** 최신 디자인이 적용됩니다. `styles/v04.css`가 빠지면 이전 버전 디자인으로 보입니다.

## 이번 버전에서 변경된 점

- 모바일 **세로·가로 각각 전용 레이아웃**. 휴대폰을 회전하면 배치가 자동으로 바뀝니다.
- 세로: 맵 중심의 전투 스테이지, 하단 고정 소환/합성/강화 조작.
- 가로: 맵을 왼쪽, 재화와 조작을 오른쪽 패널에 배치.
- 태블릿과 PC 넓은 화면도 게임판 비율을 유지하면서 재배치.
- 타이틀/난이도·맵 선택/전투/설정/캐릭터 선택/결과 UI의 시각 체계 통일.
- 원래 게임 규칙과 콘텐츠(26명, 3개 맵, 난이도, 히든 조합, 크리스탈 소환·마음의 조각 강화, 배속)를 유지.
- 새 UI도 **CSS/SVG/Canvas 코드**로 직접 구현. 추가 이미지 자산은 없음.

> 참고: 일부 모바일 브라우저는 기기 자체의 자동 회전 잠금을 풀어야 가로 화면으로 전환됩니다. 웹게임이 운영체제의 화면 잠금을 강제로 해제할 수는 없습니다.

## 테스트
