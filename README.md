# 세카이 랜덤 디펜스 (비공식 비영리 팬게임) — 이미지 없는 플레이 버전

HTML5 / CSS / JavaScript로 만든 2D 도트 스타일 랜덤 디펜스입니다. **별도 이미지 파일·서버·빌드 과정이 필요 없습니다.**

## 실행하기

GitHub Pages에 배포하거나 로컬 개발 서버에서 실행하세요. ES Modules를 사용하므로 `index.html`을 탐색기에서 더블클릭하면 브라우저의 보안 정책 때문에 실행되지 않을 수 있습니다.

로컬에서 확인할 때(선택):

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열면 됩니다. Node.js만 있다면 `npx serve .`도 가능합니다(외부 패키지가 필요할 수 있습니다).

## GitHub Pages에 공개하기

1. GitHub에서 새로운 **public** 저장소를 만듭니다.
2. 이 ZIP을 **압축 해제**합니다. `index.html`, `src/`, `styles/`, `.nojekyll` 등이 저장소 최상위에 있도록 업로드합니다. **ZIP 파일만 업로드해서는 실행되지 않습니다.**
3. 저장소의 `Settings → Pages → Build and deployment → Deploy from a branch`를 선택합니다.
4. `main`과 `/(root)`를 고른 후 저장합니다.
5. GitHub의 Pages 설정에 표시되는 공개 주소로 접속합니다.

프로젝트 페이지는 일반적으로 `https://사용자이름.github.io/저장소이름/` 형태입니다. 내부 리소스는 모두 상대 경로이므로 하위 경로에서도 실행됩니다.

## 들어있는 기능

- 3종의 코드 생성 도트 타일맵, 하나의 폐회로 경로, 별도 적 출현 구역
- 26명의 캐릭터 데이터 및 이미지 없는 앞·뒤 방향 코드 스프라이트
- 랜덤 소환 / 배치 / 이동 / 자동 공격 / 동일 캐릭터 동일 성급 합성 / 자동 합성
- 1~4성 성장, 4종의 전역 강화(공격·속도·능력·재화)
- 6개 그룹과 10개 캐릭터 페어의 히든 공격 `세카이의 마음`
- 4개 기본 난이도와 극한 클리어 후 이어지는 무제한 모드
- 1× / 2×, 일시정지, 종료 슬로모션
- 승패/실제 소요 시간/멤버별 누적 대미지 결과
- 모바일 세로·가로, 태블릿, PC 대응 CSS, 터치 선택 및 공격 범위 표시
- 한국어 / 일본어 / 영어, 브라우저 로컬 저장, 원본 이미지·사운드 무사용

## 조작

- `소환` 버튼: 캐릭터 자동 배치
- 배치한 캐릭터를 터치: 선택, 공격 범위와 정보/합성 표시
- `이동` 후 빈 칸 터치: 캐릭터 위치 변경
- `합성`: 선택 캐릭터와 같은 성급·같은 캐릭터를 합성
- `일괄 합성`: 가능한 합성을 전부 수행
- `2×` 버튼 또는 Space(PC): 전투 배속 전환
- Esc(PC) 또는 우측 상단: 일시정지

## 프로젝트 구조

- `src/data/`: 캐릭터 26명, 맵 3종, 적·난이도, 히든 조합, 다국어 문구
- `src/core/`: 전투·웨이브·합성·타이머·도트 렌더링·저장·효과음
- `src/ui/`: UI 로직과 이벤트
- `styles/`: UI 디자인과 기기별 배치
- `tests/`: 순환 경로·합성·전투 기본 로직 검사 (`npm test`)

## 이미지 교체

캐릭터 디자인은 `src/core/Renderer.js`의 `drawPixelPerson()`에 구현된 임시 코드 스프라이트입니다. 나중에 사용 권리를 확인한 캐릭터 이미지를 준비하면 렌더러만 교체하면 됩니다. UI나 게임 규칙을 다시 제작할 필요가 없도록 데이터와 렌더링을 나눴습니다.

## 공개 주의

비공식 비영리 팬 프로젝트입니다. **비영리 고지가 IP 사용·배포에 대한 허가를 의미하지 않습니다.** GitHub Pages로 공개하기 전에는 원작 및 가상 가수 관련 권리자의 정책과 팬게임 공개 가능 여부를 확인하세요. 공식 일러스트, 원본 게임 UI, 상용 음악은 포함하지 않았습니다.

## 현재 단계와 한계

이 파일은 이미지 없는 **첫 번째 전체 플레이 프로토타입**입니다. 26명 고유 외형은 임시 코드 도트로 표현했고, 공격별 수치·소환 경제·무제한 후반 밸런스는 실제 모바일 플레이 테스트로 조정해야 합니다. 협동 플레이·서버 저장·로그인은 포함하지 않습니다.
