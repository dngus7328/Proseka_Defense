# 세카이 랜덤 디펜스 · v0.2 UI 정리

이미지 파일 없이 동작하는 정적 HTML5 팬게임 프로토타입입니다.

## GitHub Pages 배포

1. 이 ZIP을 압축 해제합니다.
2. `index.html`, `styles/`, `src/`, `tests/` 등의 파일과 폴더를 저장소 `main` 브랜치 **최상위**에 업로드합니다. 이전 버전 파일은 같은 경로에서 새 파일로 덮어씁니다.
3. GitHub `Settings → Pages`에서 `Deploy from a branch`, `main`, `/(root)`를 사용합니다.
4. `Actions → pages build and deployment` 완료 후 `https://<계정>.github.io/<저장소>/`로 접속합니다.

### v0.2 수정 사항

- 불필요한 **집중 그룹** 선택 기능과 관련 소환 편향을 제거했습니다.
- 시작 화면은 모바일 풀스크린 메뉴로 재구성했습니다.
- 전투 화면에서 소환·합성·강화·세카이의 마음을 하단 조작부로 재배치했습니다.
- 빈 캐릭터 선택 패널은 숨기고, 캐릭터를 터치했을 때만 정보창을 표시합니다.
- 강화는 모바일에서 펼침 패널로 열리며, 태블릿/넓은 화면은 반응형으로 재배치됩니다.
- 새로운 CSS 스타일은 `styles/game-ui.css`에 분리했습니다. UI 이미지는 사용하지 않습니다.
- 기존 전투·데이터·언어·난이도·결과 기능은 유지합니다.

### 검증

`node tests/validate.mjs` — 맵 순환 경로, 26명 캐릭터, 합성, 웨이브, 결과 상태 검사.

참고: 브라우저 렌더링 확인은 개발 환경의 브라우저 접근 정책으로 제한되어, 실제 모바일에서 시각적 조정이 더 필요할 수 있습니다.

## 권리 관련 안내

비공식·비영리 팬 제작 프로토타입입니다. 원작 제작사 및 운영사와 관련이 없으며, 비영리 고지만으로 배포 허가가 자동으로 생기는 것은 아닙니다. 공개 전 원작 및 보컬로이드 캐릭터 관련 이용 조건을 확인하세요.

### v0.3 재화 규칙
- 소환은 크리스탈을 사용합니다.
- 강화는 마음의 조각을 사용합니다.
- 적 처치와 웨이브 보상으로 두 재화를 각각 획득합니다.
- 재화의 아이콘은 자체 SVG로 표시됩니다. 공식 게임 이미지 파일은 포함하지 않습니다.
