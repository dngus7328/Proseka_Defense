# Title artwork (creator-provided)

This directory contains the optimized title-scene assets for the layered animation.

Upload these **four WebP files** from `Proseka_Title_Intro_Assets.zip` (provided in the chat) directly to this folder:

- `title-background.webp` — cropped background
- `title-enemies.webp` — transparent enemy cutout
- `title-characters.webp` — transparent character cutout
- `title-final.webp` — complete original title illustration

All images are 1672×941. Do not resize the individual layers independently.

The title scene defaults to the existing fallback Canvas until all four files have loaded successfully, and then plays the staged entrance animation. The existing language-specific logo files are under `Assets/logos/`.

This directory intentionally tracks no image files until the images have been uploaded.
